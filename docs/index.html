hSignerBridge ký số PDF bằng USB Token, ngay trong trình duyệt
GitHub Tải hSignerBridge.exe

Demo trực tiếp

Mở một file PDF, đặt chữ ký lên trang rồi ký bằng chứng thư số trên USB Token của bạn. Toàn bộ xử lý diễn ra trên máy bạn — file PDF không được gửi đi đâu cả; trang này chỉ nạp plugin từ CDN.

1. Cài .NET 8 Desktop RuntimeBỏ qua nếu máy đã có.
2. Chạy hSignerBridge.exeIcon xuất hiện ở khay hệ thống, lắng nghe localhost:9505.
3. Cắm USB TokenePass2003, SafeNet, VNPT-CA, Viettel-CA, YubiKey…
4. Mở PDF và kýChọn chứng thư, nhập PIN theo hộp thoại của Windows.
Chrome 141 trở lên: trình duyệt sẽ hỏi quyền Local network access trước khi trang web được phép nói chuyện với ứng dụng chạy trên máy bạn — chọn Allow. Nếu lỡ từ chối: bấm biểu tượng bên trái thanh địa chỉ → Site settings → Local network access → Allow → tải lại trang. Firefox và Edge không cần bước này.

Có gì trong bản này

Xem PDF nhiều trangCuộn tất cả trang hoặc xem từng trang, zoom, Fit, kéo di chuyển khi phóng to.
Kéo-thả chữ kýĐặt chữ ký đúng chỗ cần ký, đổi kích thước bằng nút góc.
Trường biểu mẫuChữ ký, văn bản, checkbox, radio, danh sách chọn — gán cho từng người ký.
Song ngữ Việt/AnhTự chọn theo trình duyệt, đổi được bằng lang hoặc ghi đè từng nhãn.
Chạy được trên Chrome 141+Tự chuyển sang kênh HTTPS khi trình duyệt chặn WebSocket tới localhost.

Nhúng vào trang của bạn

<div id="app"></div>
<script src="https://cdn.jsdelivr.net/gh/haoquangviet/hSignerBridge@v1.3.0/web/pdfsignclient.js"></script>
<script>
  new PdfSignClient({ container: '#app' });
</script>

Nên ghim theo tag (@v1.3.0) thay vì @main, và cân nhắc dùng SRI để trình duyệt kiểm tra toàn vẹn tệp. Bản trên npm: npm i hsignerbridge → https://unpkg.com/hsignerbridge@1.3.0/web/pdfsignclient.js.
